# Introducción por función

La documentación de Adobe Commerce está organizada en varios repositorios y sitios. El punto de partida correcto depende de su función y, para los administradores y comerciantes, de la plataforma y la ruta de comercialización que utilice su proyecto. Consulte [Plataformas y servicios](../portfolio/platform-and-services.md) si todavía no está seguro de qué plataforma se aplica a usted.

## Para profesionales del sector empresarial

Descubra qué es Adobe Commerce y cómo trabajan juntos el administrador y la tienda.

- [Información general de [!DNL Adobe Commerce as a Cloud Service]](/help/cloud-service/overview.md)

- [[!DNL Adobe Commerce Optimizer role-based workflows]](/help/optimizer/get-started.md#role-based-workflows)

- [Guía de introducción de Adobe Commerce](https://experienceleague.adobe.com/es/docs/commerce-admin/start/guide-overview)


## Para comerciantes

Adobe Commerce tiene dos rutas de comercialización. El que se aplique y esté disponible depende del backend de, no de la función:

- Extensiones **[!DNL Live Search], [!DNL Product Recommendations] y [!DNL Catalog Service]**: se usa con [!DNL Adobe Commerce as a Cloud Service] y Adobe Commerce (en la nube o de forma local). Consulte las siguientes guías:

- [¿Qué es Live Search?](/help/live-search/overview.md)
- [¿Qué son las recomendaciones de productos?](/help/product-recommendations/overview.md)
- [Servicio de catálogo para Adobe Commerce](/help/catalog-service/overview.md).

- **Comercialización nativa en[!DNL Adobe Commerce Optimizer]**: se usa cuando Adobe Commerce en la nube o local se conecta a [!DNL Adobe Commerce Optimizer] mediante [!DNL Adobe Commerce Optimizer Connector]. Consulte la [descripción general de comercialización](/help/optimizer/merchandising/overview.md).

## Para administradores

La configuración difiere según la plataforma y si el proyecto usa [!DNL Adobe Commerce Optimizer]:

- **[!DNL Adobe Commerce as a Cloud Service]**: los servicios de Commerce se instalan y configuran automáticamente. Consulte [Introducción a Adobe Commerce as a Cloud Service](/help/cloud-service/getting-started.md).

- **[!DNL Adobe Commerce Optimizer]**: un producto de software como servicio (SaaS) que configuró independientemente del servidor de Commerce. Consulte [Introducción a Adobe Commerce Optimizer](/help/optimizer/get-started.md).

- **[!DNL Adobe Commerce Optimizer Connector]y[!DNL Adobe Commerce Optimizer Connector for B2B]**: Conecta Adobe Commerce (en la nube o local) a Adobe Commerce Optimizer. Consulte [Introducción al conector Adobe Commerce Optimizer](/help/aco-connector/get-started.md).

- **Adobe Commerce en la nube o local (PaaS)**: instale cada extensión de servicios de Commerce antes de configurarla. Consulte las guías de cada extensión para obtener instrucciones detalladas.

- [Introducción a Live Search](/help/live-search/install.md)
- [Instalación y configuración de Recommendations de productos](/help/product-recommendations/install-configure.md)
- [Instalación del servicio de catálogo](/help/catalog-service/installation.md).

- Para obtener información sobre la administración de plataformas para Adobe Commerce en la nube o de forma local, consulte:

- [Guía de Commerce sobre infraestructura en la nube](https://experienceleague.adobe.com/es/docs/commerce-on-cloud/user-guide/overview)
- [Guías operativas de Adobe Commerce](https://experienceleague.adobe.com/es/docs/commerce-operations/operational-guides/home) para aplicaciones locales.
