# Conectar Adobe Commerce a AEM Assets para la administración de recursos

Los AEM Assets se pueden conectar a Adobe Commerce a través de diferentes rutas de integración, según el producto de Commerce.

Para Adobe Commerce en la infraestructura en la nube, utilice la Integración de AEM Assets para Commerce. Para Adobe Commerce as a Cloud Service y Adobe Commerce Optimizer, utilice Visuales del producto con tecnología de AEM Assets.

>[!NOTE]
>
>Esta guía cubre las rutas de integración de los AEM Assets para Adobe Commerce en la infraestructura en la nube, Adobe Commerce as a Cloud Service y Adobe Commerce Optimizer. Siga la ruta que coincida con su producto e implementación.

## Primeros pasos

1. Revise la documentación de [Integración de AEM Assets para Commerce](/help/aem-assets-integration/overview.md) para conocer los requisitos previos y la configuración.


1. Para habilitar la administración de recursos con los AEM Assets, siga las instrucciones de [Pasos siguientes](/help/aem-assets-integration/overview.md#next-steps) para su tipo de implementación en la Guía de integración de AEM Assets para Commerce _[3.](/help/aem-assets-integration/overview.md)_
